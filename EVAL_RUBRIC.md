# Ralph Ledger Evaluation Rubric

Total score: 100 points.

| Dimension | Max | What It Means |
| --- | ---: | --- |
| Impact | 20 | Clear problem, audience, workflow, and practical value. |
| Technical Execution | 20 | Reproducible implementation with coherent architecture and checks. |
| Originality | 15 | Distinctive concept, framing, or interaction model. |
| Demo Quality | 15 | Clear first screen, smooth flow, fixtures, and judge-ready story. |
| Harness / Agent Engineering | 30 | Spec clarity, autonomous prompt quality, loop evidence, recovery, logging, and report readiness. |

Confidence values:

| Kind | Value | Meaning |
| --- | ---: | --- |
| Observed | 1.0 | File exists or command output is captured. |
| Inferred | 0.7 | Derived from docs, comments, or static reading. |
| User claim | 0.4 | Claimed by the submission but not independently checked. |
| Missing | 0.0 | Expected evidence was not found and should trigger a deduction. |
