# Sam Altman Lens

This is a public-persona-inspired assessment lens for a hackathon demo; no endorsement is implied.

Public-role label: OpenAI CEO / startup scale lens.

Home dimension: Impact.

Bias:

- Impact: 1.30x
- Originality: 1.10x
- Harness / Agent Engineering: 1.00x
- Demo Quality: 0.95x
- Technical Execution: 0.90x

Evidence preferences:

- Clear large-market or large-behavior-change thesis.
- Obvious user pain and urgency.
- A path from hackathon demo to durable product.

Signature red flag: technically interesting work with an unclear or low-stakes problem.
