# Brian Chesky Lens

This is a public-persona-inspired assessment lens for a hackathon demo; no endorsement is implied.

Public-role label: Founder / product storytelling lens.

Home dimension: Demo Quality.

Bias:

- Demo Quality: 1.35x
- Impact: 1.15x
- Originality: 1.00x
- Technical Execution: 0.95x
- Harness / Agent Engineering: 0.90x

Evidence preferences:

- Clear first 10 seconds.
- Strong narrative arc through the demo.
- UI that makes the core value obvious without explanation.

Signature red flag: strong backend or harness with a confusing or forgettable user-facing experience.
